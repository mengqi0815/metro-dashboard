3. 进站客流计算
3.1 进站客流 = API客运量 / 换乘系数。
3.2 换乘系数取值规则：
    - 该月速报已出：取xlsx中该月的实际换乘系数。
    - 该月速报未出：取xlsx中近3个已出月份的换乘系数均值。
3.3 各时期独立取系数：
    - 本期：本期日期对应月份的系数。
    - 环比期：环比期日期对应月份的系数。
    - 同比期：同比期日期对应月份的系数。
4. 客流不足判断
4.1 近7日：有效客流天数小于4天，渗透率显示"客流不足"，跑赢/输列显示"-"。
4.2 MTD：有效客流天数小于当月累计天数*70%，渗透率显示"客流不足"，跑赢/输列显示"-"。
4.3 日维度：当天无客流数据，渗透率显示"-"。
4.4 有效天数 = 该窗口内有API客流且大于0的天数。
5. 跑赢/输判断
5.1 赢 = 笔数涨幅大于客流涨幅（或笔数降幅小于客流降幅）。
5.2 输 = 笔数涨幅小于等于客流涨幅（或笔数降幅大于客流降幅）。
5.3 四类组合：
    - 双赢：环比赢 + 同比赢，绿色。
    - 周赢年输：环比赢 + 同比输，橙色。
    - 周输年赢：环比输 + 同比赢，橙色。
    - 双输：环比输 + 同比输，红色。
5.4 维度名称动态显示：日维度为日赢/周赢，近7日为周赢/年赢，MTD为月赢/年赢。
5.5 本期渗透率为"客流不足"时，跑赢/输显示"-"。
6. DAP涨跌判断
6.1 双涨：环比DAP涨 + 同比DAP涨，绿色。
6.2 环涨年降：环比DAP涨 + 同比DAP降，橙色。
6.3 环降同涨：环比DAP降 + 同比DAP涨，橙色。
6.4 双降：环比DAP降 + 同比DAP降，红色。
6.5 涨/降判断：DAP变化率大于等于0为涨，小于0为降。
